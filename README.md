# 🌿 르메뜨레(L.REMETTRE) 공식 프레젠테이션 & 디지털 아카이브 허브

본 프로젝트는 **기존 사내 대외비 자료(매출, 정산, 고객 정보 등)와 엄격히 분리**하여, 외부 세미나·강의·미팅 현장에서 인터넷만 연결되면 **F11 전체화면으로 즉시 프레젠테이션을 진행하고 공식 자료를 안전하게 공유/다운로드**할 수 있도록 구축된 **비용 0원(Zero-Cost) GitHub Pages 배포용 웹 프로젝트**입니다.

---

## ⚡ 문서/자료 자동 동기화 방법 (무인 자동 반영 & 원클릭 배포)

### 방법 A. [기본 동작] 백그라운드 무인 자동 동기화 & 배포 (`watch_docs.py`)
Windows 로그인 시 백그라운드에서 **`watch_docs.py`** 감시 데몬이 콘솔 창 없이 자동 실행됩니다.
1. 새로운 PPTX, PDF, MP4, 이미지, Excel 파일을 `docs/01_프레젠테이션_강의` 등 해당 카테고리 폴더에 넣거나 기존 파일을 수정·저장합니다.
2. 저장이 완료되고 **15초가 지나면** 감시기가 자동으로 **PPTX→PDF 변환 + 첫 화면 썸네일 생성 + `data/resources.json` 갱신 + PWA 캐시 버전 갱신 + GitHub Pages 배포**까지 무인으로 완료합니다.
3. 설치형 PWA 앱에서도 **삭제·재설치 없이** 앱을 열거나 화면으로 돌아올 때 즉시 최신 자료가 자동 반영됩니다.

---

### 방법 B. [즉시 수동 반영] `자료_자동_동기화_및_배포.bat` 더블 클릭
15초 대기를 기다리지 않고 **지금 당장 1초 만에 강제 동기화·배포**하고 싶을 때만 폴더 내 **`자료_자동_동기화_및_배포.bat`** 파일을 더블 클릭하시면 진행 로그를 눈으로 보며 즉시 배포할 수 있습니다.

---

### 방법 C. GitHub 웹 화면에서 직접 업로드할 때 (클라우드 완전 자동)
GitHub 저장소([https://github.com/big-kim/lremettre-hub](https://github.com/big-kim/lremettre-hub))의 `docs` 하위 폴더에 브라우저로 드래그 앤 드롭 업로드만 해도, **GitHub Actions 클라우드 러너가 자동으로 `sync_resources.py`를 실행하여 사이트에 즉시 반영**합니다.
